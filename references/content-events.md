# 内容连续表达 · 本地补丁 0.1

适用：用户要求内容接连发生、语音转动效、带 IP 的表达或基于已选样片继续创作。先继承用户选定风格；不强制深色面板、四个角色、固定镜头链或本次片子的字句。

## 先理解，再安排变化

1. 复用原声和已有转写，核对重要信息、专名、来源与不确定项。当前 Agent 负责判断重点；本补丁没有自动识别语义的模型。
2. 用短表写清 `原声意思 → 观众新看懂什么 → 画面具体改变什么 → 留下什么`。每次变化须能解释输入、关系、选择、比较、过程或结果；位移/缩放本身不算新增理解。
3. 按素材的实际内容选择用途：证据、解释、情境。照片真实不等于语义正确，不能用空白屏幕、桌面气氛代替能力演示。优先复用授权素材，登记来源、作用、焦点与裁切；未要求图像生成时不调用 Image API。
4. 先做关键状态图，暂时不加运镜和音乐：只看前后状态，也应能看懂发生了什么。缺内容先补内容，不靠漂移填时长。
5. 围绕少量持续对象逐步构成内容。已经完成的结果可留在画面里，为下一项提供上下文。不是每句话清空再换页，也不是整片必须一个固定面板。
6. 再安排主次动作、必要运镜和声音。一个时刻优先一个主焦点；其他对象可以准备，但不要同时抢读。快速揭露、清晰落定、阅读停留各有用途，不把相同缓起缓停应用于全部属性。

## IP 是参与者，不是漂浮装饰

先指定它这一幕的任务：选择、引出重点、揭示、提醒、反馈、替换。任务相同但主体换成新 IP 时，保持内容和布局，使“可替换”直接可见；没有此语义时不强制替换镜头。不同角色不默认都跳跃，也不要求每个角色展示不同的拟人技能。

只使用真实存在的图层/动作能力。原始 PNG 整体变换不等于骨骼绑定或面部动画。强调线、焦点、揭露可按既有 registry 使用 DrawAnnotation、FocusHandoff、ValueReveal 等；实际导入后才记 actual-used。

## 可复用的工程入口

填写 `assets/content-events.example.json` 的结构，示例是假设内容，不是具体用户的事实。将项目中的命名事件供文字、角色、素材与音效共同引用，避免四套各自维护的时间；组件不能只导入计划却继续完全使用另一套手写时间。

```sh
python3 scripts/content_events.py check /absolute/content-events.json --out /absolute/event-check.json
python3 scripts/content_events.py compile /absolute/content-events.json --out /absolute/event-score.json --shotbook /absolute/EVENTS.md
```

检查：事件时间、对象前后状态接续、来源引用、反馈必须指向已完成的内容事件；提示长时间无新增内容、同屏逐字重复文案及重复含义声明。2 秒仅是复查提示，不能机械要求每 2 秒动画。检查不能判断“before/after 换个名字”是否真正增加理解，也不能自动识别同义重复、运行时裁切或音乐听感。

输出 `planned_not_wired`，不是渲染器。现有选择器仍用于按语义挑机制，本补丁不新增稳定 adapter，不把受认可的定制影片包装成任意语音自动成功的模板。

## 保持验证分层

- 计划：事件图、来源与阅读预算有效。
- 接线：实际组件引用了相同事件；素材存在，反馈所指的过程确实发生。
- 画面：检查每个交接前/中/后；已完成内容没有意外消失，当前文字没有重复/互挡。
- 播放与声音：原速看，区分动作落点、语音重音和音乐重拍；合成提示音注明来源。有音乐文件或对齐时间戳，不代表听感已验证。
- 用户接受：记录用户原话及确切影片指纹。用户认可本片，不等于认可所有转写词、所有动作类型或未来任何内容。

连续性不是过度移动。镜头只在需要揭示关系、查看细节或给下一条信息腾空间时使用，不能默认套“特写→拉开→推入→拉回”。

## 本机认可基准

若 `.local/baselines.json` 中有 `content-events`，且当前用户没有另选风格，可优先沿用它的字体、配色和逐项构成方式。用既有 `motion.py baselines` / `motion.py reuse --baseline content-events ...` 创建新工程，原样副本标 `reference_copy`。改口播时必须重选信息与事件时序，更新原声、字幕、媒体与音轨，不能沿用旧句子或音乐锚点冒充新片。

本机索引和接受记录只保存本地路径与指纹。用户原声、IP、参考视频及原片不进入公共 Skill 包；不恢复已撤回的图像生成/立体艺术风格补丁。
