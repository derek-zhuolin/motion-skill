从 emil-design-eng 借鉴：先决定动作的用途与发生位置，再选曲线；保持作品的运动性格，减少无任务的装饰。从该仓库的 apple-design 借鉴：以当前呈现状态衔接，考虑余势，保持明确空间线索。apple-design 是该仓库对 Apple 设计思想的整理，不是本 Skill 获得 Apple 官方认证。

## 本 Skill 的迁移判断

固定视频无需照搬交互中断逻辑；用同一帧轴和共享轨道表达可追踪的延续。小反馈可快，阅读和解释按信息量留时。来源位置展开、轻微错位、接触后收尾可作为影片方法；不把 UI 的短时长规则施加到整个镜头，不把实时网页 GPU 优化当成 MP4 观感保证。
