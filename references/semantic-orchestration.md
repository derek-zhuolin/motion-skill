# 从内容到镜头：先说明，再实现

## 一次生产只做一份短清单

1. 看源内容：复用已核对转写；查看本地图片/视频，写一句该素材实际证明或解释什么。快照、推测、原话分别记录。
2. 定焦点：每段只传达一个主结论，确定读完它的窗口。后继元素可以提前准备，但不能抢走未读完的信息。
3. 选机制：从任务适配候选选主效果，再选必要的辅助。沿用字体/材质/运动习惯，重选布局和交接。不是复制AME固定顺序。
4. **开工前在对话展示镜头表**，含研究编号、组件名和用途；不让用户猜会出现什么，也不需要每镜再等一次批准。
5. 实际实现并保存 actual-used：只有真实导入与调用才算使用。之后看进入/中间/离开的画面，再原速连看。

简表列：`镜头/时间 | 本段意思与焦点 | 主效果编号/名字 | 辅助/转场 | 选择原因 | 读完时间`。
用户说“十几组”时先理解成可选范围，除非明确要求，不把10、15或96设为每片使用配额。
研究编号表示机制来源；同一研究可以有多个生产组件。自定义组合标“custom”，注明组成与代码，不冒充库内成品。

## 内容决策表

| 当前内容 | 主机制候选 | 动作的意义 | 约束 |
| --- | --- | --- | --- |
| 一个当前数值/数量 | #35 number-reel；#31 value-reveal | 让眼睛落到实际数字 | 保留时间与单位，滚动不代表真实增长；0不是缺失 |
| 两期变化/两个方案 | #43 numeric-comparison | 同屏比较，第二项拉幕揭露 | 两个来源、时间与可比单位；不自动推断因果或百分比 |
| 一句结论/短关键词 | #31 line-reveal；#11 keyword-rhythm | 先主张，再层级 | 不逐字打散需要整体读懂的短语；完整显露后才开始算可读窗口 |
| 文字引出一个实物/画面 | #10 keyword-window | 从概念深入对应素材 | 遮罩内部必须与这个词相关；缺素材改用文字表达 |
| 截图/数字证据 | #27 media-focus + #36 draw-annotation | 让观众找到证据原位 | 先看实际素材，标记区域，保留作者/时间/限制 |
| 本身有动作的真实视频 | #27 media-focus 的 hold 模式 | 借原片动作推进 | 先固定外框，不再强加全局漂移；不要修改身份/配色 |
| 关系汇合/模块协作 | #19 clay-join | 两个对象接触形成关系 | 真有两个参与者才用；不能只为展示粘土 |
| 下一镜继续同一对象 | #38 focus-handoff | 将注视点交给下一处内容 | 前后要有同一对象或明确指代；必要切镜可以直接切 |

`select-motion` 读取 Agent 已解释的 kind/intent/purpose，不做原始自然语言或媒体识别。Agent先从当前项目最近已实际使用的清单提取 recent_mechanisms；没有记录就明确为空，不扫描无关项目。候选按适配性和近期使用排序，兼顾同一研究家族的重复；同一内容可有不同合适解法，但不随机变化。复杂空间/相机/遮罩需要定制，现有10个adapter不是全部96项研究的实现。选择器是这些已覆盖类别的快捷入口，不是所有影片都必须套用的唯一模板。未覆盖的关系保留原意，按catalog取研究做custom；同样先给编号镜头表，并记录实际源码、相关验证和仍缺的能力，不能为了让校验通过而改写故事。

## 连续性比转场数量重要

- 下一步为什么出现：深入证据、对比、选择、汇聚、结论，必须有一句解释。
- 定义主体身份 `object_ids`、主注视点 `focus_object` 和 `handoff` 的去向/时刻；跨镜保持形状、位置或语义对应至少一项。
- 关注正在读的对象。阅读结束前不得退出；配角预备不代表全文同时进场。
- 连续不等于一直移动。安定阅读区与短促变化交替；不要每一镜都“滑入—停—滑出”。
- 数字自身、关键词自身、素材内部必须承担至少一种与意思相符的动作；全局运镜只承担导航。
- 不要求每镜都使用动画。素材本身清楚且有动作时，静止外框可能更好。

## 计划、接入、验收三种状态

`selection.json` = planned_not_wired；`production-manifest.json` = 实际调用声明；源码审计 = 仅接线检查；真实关键帧/播放 = 画面证据；用户确认 = 人类验收。不能相互代替。

输入示例：`assets/semantic-plan.example.json`。示例内容明确标为测试，不代表真实项目效果。

```sh
python3 scripts/motion.py select-motion plan.json --out selection.json --explain shot-plan.md
python3 scripts/motion.py audit-production production-manifest.json --project /absolute/project --out new-audit.json
```

actual-used 每条记录：镜头、时间、adapter、study_id、调用文件、原因、素材来源、实际改变的对象；最终交付要说明相对计划改了什么及原因。未用的候选不能计入已使用数量。

只调整局部时复用本次已读的规范、素材与转写，避免再次通读研究库。新增内容类型时才补相关参考与测试。
