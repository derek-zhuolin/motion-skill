# ACE-Step：首次下载与等待时间

ACE-Step 是可选的外部本地音乐生成工具，不是 Motion Skill 自带模型。**只想试律动 Playground，不需要安装 ACE-Step**；示例随代码合成测试节拍。有现成且获授权的音乐，也可以直接进入配乐与画面的编排。

## 第一次使用先知道这几件事

- **下载比较大**：上游安装指南列出核心模型约 **10GB** 磁盘需求。实际组合可能是数 GB 到 10GB 以上，加上 Python 依赖、可选语言模型及缓存还需要更多空间。上游首次运行可能自动下载模型；请在执行前告知使用者并确认其选择。
- **首次不只是生成**：下载 → 安装依赖 → 加载模型 → 生成音乐，是四段不同的等待。首次下载可能需要几十分钟或更久，取决于网络、镜像和所选模型；本项目没有测得一个可承诺的首次总耗时。
- **缓存可复用**：已经下载的模型通常不用每次重下。重复失败先查下载、内存、健康状态或任务状态，不要不断重启同一个生成请求。
- **本机实测只作参考**：一次 Apple Silicon / MPS、turbo、关闭语言模型的实验生成 29 秒、请求 116 BPM 的无歌词配乐，服务记录的生成时间为 **243.75 秒（约 4 分 4 秒）**。这不含下载/首次加载，也不是别的机器的性能保证；请求 BPM 不等于成品每个强拍都准确。

以上实测为 2026-10-28 的单次记录，不包含个人配音，也不公开本机日志与路径。硬件和模型选择不同，耗时及效果会变化。上游要求与下载说明见 [ACE-Step 官方安装指南](https://github.com/ace-step/ACE-Step-1.5/blob/main/docs/en/INSTALL.md)。

## 推荐制作顺序

1. 确认片长、是否纯音乐、风格、已有音乐是否可用；新生成先只做一条短样本。
2. 试听音乐结构，记录可用段落和真实起音。能播放、BPM 字段正确，不代表风格满意。
3. 将重要语义落点与音乐起音结合，给读数/证据保留停顿；真实视频和原声保持原时间。
4. 音乐、人声、动作音效分轨制作，在点击/进入/落定处安排少量动作音效，并检查人声清晰度、峰值和尾部。
5. 原速看听；换音乐后时间锚点与旧审片报告失效，重新核对。先通过 Playground，再决定扩展或导出。

**生成配乐、设计动作音效、挑选节奏落点，是三件事。** 本次工作流支持把它们组合，但没有自动识别所有强拍、自动配好每个音效或保证 K-pop 风格的功能。音乐质量与律动仍由实际试听决定。示例测试音只验证播放器与时间同步，不能用来证明 ACE-Step 的音乐品质。

安装和调用请使用上游当前文档或已安装、明确授权的 ACE-Step Skill；本仓库不静默安装模型，不捆绑下载，不修改服务配置。
