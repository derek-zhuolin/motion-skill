# 已认可的连续粘土方向 · v11

用户在 2026-11-03 明确认可 polish32 的完整效果，并授权整理为本地补丁和 GitHub 源码更新。认可属于这支影片，跨新音频的稳定性待下一轮测试。读取 `directed-profile.json`；有本机 `.local/accepted-motion.json` 时，查看其中实际工程、Playground 与验收证据。

## 新音频的最短路径

1. 用 `motion.py brief --audio /absolute/audio.mp3 --out /absolute/new-run --prompt-file /absolute/request.txt` 创建新 run。命令只核音源、保存要求和复制可复用源码；状态为 `prepared_not_film`，不会转写、调用模型或生成片子。
2. 按音源 hash 查转写缓存；命中后核对覆盖、专名和时标，没有再走已授权的转写工具。保留原声 1×，不要用旧字幕覆盖新音频。
3. 读内容，确定观众最后记住的画面。给出简短的“意思→主体→变化→阅读→交接”安排，随后直接实现。只在构思确有分歧时比较备选，不要求每次写两套形式相似的方案。
4. 在完整界面和具体物体中选择载体；原组件、Stageshow、官方 Elements、真实素材各自承担任务。UI 外壳与内部内容分开，页面交接保留同一窗口；几何只由一个层负责。需要 custom 时准确标明，不拿研究 ID 代替实现。
5. 先按用户指定范围做 Playground；未指定通常取 15–20 秒完整意思。一个主动作后，先交代结果再接下一步。对关键交接看前、中、后帧，原速播放；发现问题最多做两轮有针对性的修正，仍有缺口准确报告。用户反馈后保留已认可部分再修。

不重建已认可字体、配色与材质；新内容重新选择镜头，不能复印 polish32 的时间表、手机或三卡布局。用户明确提供其他品牌时，品牌文件优先。

## 从今天的反馈保留下来的判断

- **节奏**：信息密度来自可见状态变化、疏密和景别变化，不等于一直快、一直动。镜头移动要带来新信息。主动作可快，结果要读得完；不要同时发动镜头、主体、文字和装饰。
- **层次**：蓝色/深蓝承托白色 UI，前景主体与背景有材质、尺度和明暗区别。圆角、柔和渐变、厚度、接触影共同构成粘土；一个投影或蓝色 Icon 不足以替代。
- **UI**：完整产品界面可以进入特写，内容也可以从界面接出。窗口不是一张无状态的装饰卡，操作有对象、过程、结果；不要只剩悬空按钮。
- **文字**：短句分意思显露；快速段优先图像、UI 或物体。字幕是辅助，不能成为全片唯一的动画。不要密集解释卡和遮住结果的重复标题。
- **变化**：归位、揭示、复制、翻面、展开、直接切换按语义选择。争取一处令人记住的有含义转折，不强制每段翻转，也不固定一套转场重复全片。
- **素材与声音**：使用真实、相关、有来源的摄影或视频；不要反复循环不合适的 stock。人物与商业摄影气质按当前要求选择，不能由外表猜身份。少量音效服务接触和结果，原声优先。
- **反馈学习**：保留用户认可的维度与被否定的细节；区分“本片接受”“可复用机制”“新内容未验证”。不要把候选方案、测试通过或 Agent 自评写成用户认可。

## 实际组件入口

均使用 composition 的同一个 `frame`；`from/to` 单位是帧，先从新的音频事件换算，不抄旧秒数。

| 导入 | 用途 | 边界 |
| --- | --- | --- |
| `DirectedPolish.PhraseReveal` | 一个语义块从裁切窗口显露 | 不是逐字打字；调用方选择分句 |
| `DirectedPolish.PageHandoff` | 同一窗口内部的页退出/进入 | Window 留在父级；不叠两套界面 |
| `DirectedPolish.CardResponse` | arrive / receive / recede 的一次反馈 | 放到真实卡片上，不循环晃动 |
| `DirectedPolish.NavigationCue` | 提前指出下一处内容 | 导航结束后再安排主操作/靠近 |
| `DirectedPolish.TraceRule` | 一个重点短线描出 | 不是每句都画线 |
| `DirectedPolish.TraceConfirm` | 真实结果完成后的确认 | 不能用对号代替过程 |
| `SoftClay.SoftClaySurface` | 已认可材质的圆润、柔光和体积 | SVG 模拟体积，不是 mesh |
| `SoftClay.SoftClayJoin` | 接触时的轻压缩 | 同一个对象保留身份 |

`motion.py direction catalog --query 换页` 等可以发现这些入口。它们被复制进工程还不等于已经使用；需要在实际影片 import/JSX 调用，并查看可见画面。旧 10 个基础 adapter、9 个 UI frame、材质、数据与运镜扩展继续可用。96 项仍是研究范围，不是动效配额。

## 验收回答是 / 否

当前主角是否一眼明确？动作之后是否看懂了新信息？粘土是否真的有柔和曲面和重量？相邻镜头能否追踪同一对象？结果是否在完全出现后留读？快段是否避免密字？是否有适合内容的变化而非重复入场？原声是否保持、声音是否不抢话？组件是否实际可见？是否原速播放检查？

将缺口写出来，不能因编译成功一律勾“是”。下一段音频测试时，同样检查这些问题，并额外看是否真的重新编排；不要用同一句口播反复证明可迁移。
