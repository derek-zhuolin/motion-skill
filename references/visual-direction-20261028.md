# 连续运镜与反静态卡片复盘 · 本地 2026-10-28

用户对 Terra 多版指出：卡片拼接与数据页像 PPT；Motion Skill 应形成主要视觉，真实视频是叙事的一部分，视觉统一、色彩克制，镜头和音效有张力。Computer use 只是主题的一部分、数据要讲清、结尾要有真实判断。用户要求至少三组效果是该项目的要求，不转成所有影片的固定配额。新版 v5 已做连续画布和样帧检查，用户尚未验收；不能把它当作已被接受的风格模板。

## 导演选择

1. 辨认信息关系与主焦点，先写两种不同构思及取舍，确定颜色、材质、字体及真实素材如何属于同一世界。用户指定参考的动态研究要保留编号、实际机制、来源与定制实现；选择器计划不等于实际调用。
2. 每次转场写清镜头从哪看向哪、哪个对象仍被看见、动作如何引出下一信息、何时可读。不要强制一镜到底，不要每句一张新卡片，也不要把整张网页当成唯一运动图层。
3. 真实视频优先展示可辨认的行为，图形和文字与视线、路径或节奏交接。来源、原身份和改色/裁切应可追溯；不要把第三方演示说成特定产品实录。
4. 数据先回答“测了什么、分母是什么、结果和局限是什么”，再选择数字、图形和动效，给完整读数留足时间；不要靠随机曲线或夸张比喻代替解释。判断要有证据和范围，不编造评价。
5. 快慢相间，让音乐与动作呼吸；不要固定间隔重复同样进出场。明确音乐或音效是已有素材、人工安排还是实际生成，不声称自动找拍、自动混音或完成听检。

## 检查与边界

- 看关键交接前、中、后，检查字幕、数据停留和移动方向；重点在屏幕中时不得突然卸载或遮盖。通过数字检查不代表视觉自然。
- 原速完整观看并听检；未能执行或无法可靠听到时明确标未完成，不把帧截图与音轨时长当作审美或听感验收。
- 不固定颜色或强制灰度；遵循品牌与用户要求，真实标识保持可识别性。公共使用前说明素材许可状态。
- 复用有授权的音源和素材；没有音源时明确静音。用户明确指定时长或视觉路线优先。
