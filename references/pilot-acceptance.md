# 先样片，再扩整片

默认样片为 15–20 秒、保留完整句意与上下文的源片段。显式要求其他时长或直接整片时遵循本次用户范围。原声 1×；来源相同就复用可用转写，不为了测试再次 ASR。

## 对齐验收

1. **意思**：观众能复述这一段的一个主要结论；真实证据、解释图和情境素材用途清楚。
2. **连续**：能跟住正在看的对象；交接表达选择、汇聚、揭示、因果等具体意思。允许合适的切镜和阅读停顿。
3. **可读**：主信息读完再移开，后进入的细节不抢焦点；字体和背景对比清楚，字幕不被遮挡。
4. **风格与变化**：保持参考的字体、色彩、材质与运动习惯；根据新的信息关系选择布局与镜头，不固定重放参考片组合。至少用另一段不同含义的短内容检查这种变化；不必同时做多支完整片。
5. **实际媒体**：正常速度带原声播放，再静音看交接；确认文件可解码、声音与源时间对应、素材有来源。技术检查不能判定看得懂或好看。
6. **花费**：分别记录缓存/转写、素材准备、编排、构建、关键帧、导出与验证。等待用户和中断单列；不把总用时都称为渲染或模型生成。

可用 Playground 隐藏版本标签、随机交换 X/Y 位置，支持揭晓、原速/慢看和同步定位。同一对照使用相同原声、范围与时长；不同内容测试另列。用户可先指出更自然的一版以及没看懂的时刻。隐藏标签只是一种比较方式，不宣称正式盲验已通过。

## 工程记录

当前 `pilot_gate.py` 是“复用已有转写的原声 MP4 样片”记录检查器，要求 source_excerpt 与 mp4。纯文案、首次转写或仅 Playground 的任务不套这个检查器；按上述适用项记录真实预览/素材证据及人工反馈，不伪造音轨、转写复用或 MP4。它不负责解码媒体，技术字段由实际检查后填写。


每段保存 `pilot-review.json`，包含 sample.duration/audio_speed/asr_reused、artifacts.mp4/source_excerpt、technical 检查和 human_review.status/direct_user_evidence。初始人类验收为 pending。`python3 scripts/pilot_gate.py /absolute/pilot-review.json` 只检查记录，不写入接受、不运行整片。

人类确认必须来自本次用户选择/消息，禁止用自动测试结果、AI 自评或旧片已被接受来代替。样片被要求修改则记录 revise，先修当前问题；被用户接受后，再保持已选基准扩整片。内容或视觉方向发生实质改变时重新检查受影响的样片。
