# 最近两轮连续预演复盘

此文仅保留通用编排经验，不包含私人项目过程或媒体。技术检查与用户观感分别记录。

## 发现的问题

1. **把可读性变成全画面冻结。** 阅读时 camera 必须完全恒定的断言，迫使大移动挤在短间隙里；容易形成快速移动、长停留、再启动。应保护正在读的对象，允许次要层准备和收尾。
2. **数学连续不能证明影片连续。** 一条带恒值平台的连续曲线仍会反复停车。保持同一 ID 也不证明身份在像素里可追踪。
3. **整页 PNG 只有整体变换。** 页面真实，但整张平移、整页遮罩交换会反复呈现翻页语法。按需要拆少量身份、证据裁片和标题，同时保留来源与上下文。
4. **统一规则被误写成同步动作。** 统一字体和材质不要求同一位置轨道、同一启动时间或同一曲线；也不要求每个图层都独立运动。
5. **时间散在各处。** 镜头、文字、遮罩、音频和检查各写一套秒数，局部修改容易失配。语义事件必须单点定义，其余时间从事件派生。
6. **接入研究不等于用好研究。** 一个完整短语传给词组组件，并未建立词组之间的节奏；仅标注研究 ID，不能证明机制存在。96 项不是每片使用配额。

## 迁移边界

这些是从局部试作提炼的方法，不能视为任意题材的固定镜头表。保留被用户选定的视觉基准，未被选择的实验不自动变成默认模板。每次以当前内容和真实观看反馈决定分层与运动强度。

## 防止再次变成 PPT 的工作记录

每次交接写清：当前读什么、什么对象继续在场、上一动作给下一步创造什么条件、哪一层先准备、哪一层负责收尾。允许停顿，也允许有意义的直接切镜。每个新结论不自动触发新画面；不要给每句口播复制“标题＋中央卡片＋统一入场”。

先选最少的组合和轨道，做包含前后文的短连续预演。没有来源联系时，干净切镜优于强行变形。对比时固定内容、字体、配色、时长和音频条件，说明比较的是整套编排还是单变量。保存用户选择，保留未选版本，但不让它覆盖已选基线。

## 硬编码的边界

固定字体角色、品牌色和材质 token 是一致性；每条音频的语义时刻不同，不能固定成模板秒数。时间集中到命名事件；页面位置来自实际布局和裁片，不用一套坐标硬套所有页面。测试查时间依赖、素材、非有限值、焦点可读和确定性，不要求所有场景全机位静止。
