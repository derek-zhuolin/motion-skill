## 安装与更新入口验证

在独立项目目录中使用 Skills CLI 1.7.4，从公开仓库安装 `motion-video`，再验证 `update motion-video -p`。为触发真实重新安装，只改测试锁文件的内容 hash，并加入测试用的本地改动与额外文件；这不是一次历史版本升级测试。更新后 247 个安装文件逐个恢复原始 hash，目录之外的备份保留；测试本地改动被替换、额外文件被移除。因此文档明确要求先备份，不能把 CLI 更新说成自动合并工具。

核对该版本 CLI 源码发现 `check`、`update`、`upgrade` 进入同一更新流程，故不将 `check` 写成只读检查。全局与项目范围参数按官方文档及实现核对；实际写入测试只在独立项目范围执行，没有运行全局更新或修改现有 Skill。新补的 README、FAQ、更新页与更新日志检查本地链接、差异和公开文件范围；本轮不修改视频源码、不重新渲染。发布对应的远端 CI 结果以 GitHub Actions 为准。
