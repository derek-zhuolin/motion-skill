# 今天的需求收敛与已认可版本

## 最终决定

用户认可 polish32：“我觉得这一版本的效果是 OK 的”，并授权本地打补丁、整理上传 GitHub。此前的 simple32 获认可的是小动效方向，不能把之前所有实验都标记成通过。

目标是：以后提供音频和一个简短提示，Agent 能沿用相近的视觉质量重新编排。下一段新音频尚未测试，因此当前是**单片视觉通过、可复用组件已整理、新内容迁移待测**。

## 保留与避免

| 维度 | 要保留 | 要避免 |
| --- | --- | --- |
| 视觉身份 | Motion 蓝、原中文字体、圆润渐变、体积和接触影 | 为了升级换成另一种蓝、扁平卡片或硬亮塑料 |
| 叙事 | 一个清楚主体，动作改变信息关系 | 单纯信息陈列、中央标题加孤立 Icon |
| 节奏 | 疏密、快慢、近景与完整界面交替 | 前半平后半猛；每个元素同时发动 |
| 转场 | 先引导下一处，再交接；同一界面保留外壳 | 突然卸载、叠字、换页时窗口丢失 |
| 小动效 | 卡片、内部文字、导航和状态分别响应 | 只有字幕在动，所有卡片同一种飞入 |
| 惊喜 | 内容需要时让熟悉对象改变用途 | 无理由翻转、堆叠运动或强制每镜 zoom |
| 阅读 | 完整结果出现后留时间，配角可轻微变化 | 没读完就走；或整片冻成 PPT |
| 真实素材 | 现代都市商业摄影、场景相关、有来源 | 土气、不相关、反复播放同一段素材 |
| 原声 | 原音频 1×，少量有意义音效 | 偷改语速、重新配音覆盖原声 |
| 组件 | 按意思选旧能力和新能力，实际导入并看效果 | 把 96 项研究当作必须用完的模板 |

## 这次落地

- 可复用的柔和粘土材质；分句揭示、窗口内换页、卡片反馈、导航预告、描线和确认组件。
- 简短默认调用词、完整导演要求、新音频准备入口，以及源音频指纹与待验收状态。
- 当前片子的具体构图、时间点和照片只作为案例；不固化为全局模板。
- 本机保留认可影片与原声；公开源码不携带本机路径、私人音频、转写缓存或品牌私有文件。

## 下一轮怎么试

给一段新音频，直接使用 Skill 随附的 `references/audio-directed-prompt.md` 短版。先做约 20 秒完整意思的 Playground。重点看新内容是否选了合适载体和动作、是否仍有主次与粘土层次，以及是否摆脱了旧片手机→三卡的固定顺序。

好的提示要说明目的、必须保留的视觉和输出范围，不需要罗列组件编号。遇到问题优先描述“某秒谁应该先动、结果何时读”，而不是反复要求“更高级、多点动效”。
