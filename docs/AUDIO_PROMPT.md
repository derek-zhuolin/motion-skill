# 音频 + 提示词：日常调用

把下面一段与音频一起交给 Agent。附件之外只需补充你本次特别在意的一点。

> 用 Motion Skill 做这段音频，沿用已认可的 polish32 的视觉质量：Motion 蓝、原字体、圆润有重量的粘土，以及真实素材与产品 UI 的结合。保留中文原声和原速。
>
> 请先理解内容，决定观众最后应记住的一个画面。按这段音频重新编排，不照搬旧片的手机、三张卡片、镜头顺序或秒数。每段主角清楚，卡片进出、文字出现和界面切换各自服务于内容；镜头提前引导，动作揭示新信息。让片子有一次有意义、眼前一亮的变化，同时保留结果的阅读时间。
>
> 不要只动字幕，不要每段重复同一种入场，不要靠堆文字或无意义漂移增加密度。白色界面可用蓝色或深蓝承托；需要人物情境时优先使用有来源的亚洲人物真实摄影，气质偏现代都市商业片。少量音效服务于接触和结果，不盖过原声。
>
> 先做 20 秒、意思完整的 Playground。你负责选择并实际调用合适组件，检查转场前中后、文字与画面主次，再原速播放。告诉我关键动作让观众看懂了什么、哪里停下来读。缺素材或适配直接说明；先不渲染视频，不擅自更新正式 Skill。

## 想简短一点

“用 Motion 做这段音频，沿用 polish32 已认可的蓝色粘土质感和连续编排，按新内容重新设计。主角清楚，有一次有意义的亮点，读得完，别只动字幕。保留原声，先做 20 秒 Playground，不渲染。”

## 哪些补充最有用

- 本次目的：“让观众理解这个操作为什么省事”，比“更高级”具体。
- 本次重点：“我最想让人记住从杂乱变成清楚”，比“多加动效”具体。
- 局部反馈：“第 8 秒先让卡片落稳，再出现结论”，比“整体慢一点”具体。
- 若要整段，明确说“直接做完整音频”；若提供品牌规范，明确本次品牌覆盖默认配色。

这些提示提高协作一致性，不保证任意音频一次达到相同品质。跨内容复用要用新音频检查，不能用旧片的认可代替。
