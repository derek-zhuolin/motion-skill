# 可复用提示词

## 一句话

> /motion-video 把音频做成“实拍素材混剪＋MG 动效”：具体场景用实拍，抽象关系用动效。没有素材就让 Codex 联网找有使用许可的实拍并保留来源。保留原声，补同步底部字幕，片尾放大名称并停留至少三秒。

## 指定比例

不指定时默认 **16:9横屏**（示例成片1920×1080）。需要竖屏时明确写：

> 这条使用 **9:16，1080×1920**。按竖屏重新排标题、实拍、动效、底部字幕与ending，保留原声1×。

> 这条使用 **3:4，1080×1440**。按3:4重排画面与字幕，确保文字可读、主体不被裁掉。

比例写宽:高。当前模板默认横屏；其他比例需要Codex调整工程与布局并复看，不是现成的自动比例切换。

## 完整输入

> /motion-video 请用这段真实音频制作视频。受众是 **[谁]**，只带走 **[一个结论]**，画幅 **[不写时默认16:9；需要时明确写9:16或3:4及成片尺寸]**。
>
> 如果我没有提供实拍素材，请按口播的具体场景，自行联网搜索、下载并选取有明确使用许可的公开照片和短视频，记录作者、原始页面和许可证。素材受限时说明缺口，不自动付费，也不把生成画面当实拍。
>
> 先核对录音时长、文字和时间轴。原声完整保留、1×。选择有来源与许可记录的实拍照片和短视频，按语义补充场景；实拍视频每段约 3–6 秒即可，按内容决定数量，并静音以免盖住口播。抽象流程与关系用 Motion Graphics 解释。
>
> 补上随原话更新的底部字幕，与主标题、照片和人物留出空间。字体要清楚，短句断行，别为塞进字幕而缩成小字。
>
> 视觉延续 **[配色/品牌/参考]**。每屏一个主焦点，对象交接要能看见；阅读时少动镜头。
>
> ending 用 **[名称]** 做大字主视觉，配 **[一句短句]**，稳定停留至少三秒；只有我提供链接才放链接。如果原声时间不够，先说明需要怎样加尾板，不移动后段人声。
>
> 输出真实有声 MP4、可编辑工程、字幕文件、素材来源和检查记录。保留原件，使用新 run。

## 修改 reference

> 保持音频时间、字幕和其他镜头不变，把 **[时间]** 的 **[具体画面]** 改成 **[目标]**。先指出会影响哪些对象和阅读时间，再完成新版本。

> 只上传经过检查的发布副本。清理位置/设备元数据、私人文件名、绝对路径、密钥和无关历史。原始录音与原始 ASR 不上传。保留公开参考者、素材作者和许可证，不把脱敏变成删除署名。
