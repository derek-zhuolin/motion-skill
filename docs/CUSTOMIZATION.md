# 配色与版式

欢迎按自己的品牌与喜好修改。改完先看浅底、深底、字幕和 ending，再渲染整片。

## reference 主配色

编辑 `examples/voice-to-video/src/theme.json`：

```json
{"blue":"#0070DB","ink":"#141414","paper":"#F5F5F2"}
```

`blue` 是沿用的键名，含义是强调色，不要求一定使用蓝色。

| 起点 | blue（强调色） | ink | paper |
|---|---|---|---|
| 蓝 | `#0070DB` | `#141414` | `#F5F5F2` |
| 紫 | `#6C4DE6` | `#171326` | `#F6F3FF` |
| 珊瑚 | `#D94736` | `#221816` | `#FFF7F1` |

主文字、画布、胶囊、强调线与 end card 会跟随配置。实拍照片/视频、白色反差字、灰阶线和材质高光有各自职责，不会自动全片换色。换很浅的强调色时，检查白字对比并按需调整源码。

## 新片模板

修改自己的 `story.json`：

```json
{"brand":{"blue":"#6C4DE6","ink":"#171326","paper":"#F6F3FF"}}
```

然后重新 `plan`、构建、预览。不同项目的主题独立，默认不会改研究档案或已导出视频。

## 96 项研究

主色入口是 `assets/runtime/src/studies/palette.json`：

```json
{"accent":"#0070DB","ink":"#141414","paper":"#FFFFFF"}
```

这会改变研究实现的主要色值；光学近似、金属反射、阴影等仍有局部材质色。进一步调色请改对应研究文件，不宣称一键完整重着色。

## 字幕与画幅

**默认16:9。** 提示词未说明时采用横屏；需要竖屏时写明“9:16，1080×1920”或“3:4，1080×1440”。其他比例同样明确宽:高与需要的分辨率。比例决定画布形状，像素尺寸决定分辨率，两者不是同一个概念。

以上是给Codex的目标要求。当前通用模板没有自动画幅切换：要同时调整Composition/Player、画布坐标、文字字号、实拍取景、字幕安全区与ending，再实际复看。

reference 字幕样式在 `examples/voice-to-video/src/Captions.tsx`。当前基准画布1600×900，导出乘1.2到1080p；字幕在770–826px区域，字号38px（导出约45.6px）。换成竖屏要重新排版与确认安全区，不能只改视频宽高。

## 贡献

请附换色后的浅底、深底、实拍和 ending 截图，说明哪些 token 改变了。新增研究请保留来源和许可说明；调色本身不新增研究计数。
