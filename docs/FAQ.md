# Motion Skill 常见问题

[回到首页](../README.md) · [开始制作](GETTING_STARTED.md) · [提示词](PROMPTS.md)

## 不想出镜，但有想法想分享，适合用吗？

适合。用手机把想法录下来，再让 Codex 配合 Motion Skill 编排实拍、动效和字幕，就可以用声音表达观点。你不需要拍自己的脸，但仍需核对转写、内容与最终效果。公开声音不等于匿名。

## Motion Skill 是什么？和视频生成模型有什么区别？

它是一套给 Agent 使用的制作说明、Python 工具和 Remotion 工程。Agent 理解内容并修改工程，Remotion 渲染画面。它本身不是从文字直接生成真实影像的模型，也不是独立的一键视频应用。

## 需要准备什么？只有文字可以吗？

最直接的是一段已获使用授权的录音、想表达的结论、目标受众，以及想要的片尾名称。有文字时，可以先自己录音或另行使用获授权的配音工具；仓库没有内置 TTS 或声音克隆。语音转写也需要外部工具，重要字词与时间要核对。

## 没有真实图片和视频怎么办？

可在提示词中要求 Codex 按口播场景寻找有明确使用许可的公开照片和短视频，并记录作者、原始页面与许可。需要可用的联网工具；Skill 本身没有素材搜索 API。下载受限或需要付费时先说明缺口，不自动购买，不把生成画面标为实拍。参考片采用的素材与来源见[制作记录](REFERENCE.md)。

## 默认尺寸是多少？能做 9:16 或 3:4 吗？

未指定时默认 **16:9**，参考片为 **1920×1080**。可明确要求 **9:16（1080×1920）** 或 **3:4（1080×1440）**。当前通用模板固定横屏，Codex 需要调整 Composition、Player、画布与版式，并检查字幕安全区；不是只改比例参数就自动适配。比例是宽:高，像素尺寸是实际分辨率。

## 字幕和 ending 会包含吗？

voice 模式默认要求帧级字幕，明确不要字幕时可关闭。参考片包含 25 条底部字幕和独立 SRT；主标题和底部字幕分工不同。片尾可要求放大名称、添加短句并稳定停留；原声不够时需说明尾板时长，不为凑节奏偷偷变速或移动人声。新工程需要按目标实现与复看，不能以字段存在代替画面检查。

## “96 项动效”是不是都能一键套用？

不是。仓库有 96 项机制研究、19 个分类，以及 5 类通用语义 renderer。研究可以帮助设计和实现，不等于 96 套完整生产模板，也不是 96 项原创发明。历史组合没有在当前 UI 开放。逐项目录见[效果索引](EFFECTS.md)。

## 可以改配色吗？

可以。reference 修改 `examples/voice-to-video/src/theme.json`；新片模板修改 story 的品牌颜色；研究主色修改 `assets/runtime/src/studies/palette.json`。照片、视频和部分材质不会一起自动改色，详见[配色说明](CUSTOMIZATION.md)。

## 是用什么模型做的？必须用同一个吗？

公开案例标注为 **Codex + GPT-6.1 Sol**（模型名称按作者提供），本地 Whisper 转写、Remotion 渲染，并经过作者反馈调整。Skill 的工程结构不绑定这个模型，但本案例不证明其他模型有相同效果；运行它需要具备文件编辑和命令执行能力的 Agent。

## 免费吗？能直接商用或转发素材吗？

仓库可公开获取，但 Agent、外部服务、素材和依赖可能各有费用或许可条件。项目自有工程采用有明确范围的 MIT；历史研究档案、第三方字体、依赖、实拍素材与示范片并非统一 MIT。1–64 项的早期逐项出处仍不完整。复用前按[许可范围](../LICENSE_SCOPE.md)核对对应部分，不能把仓库里的内容整体当成可任意再分发的素材包。

## 本地预览与检查通过，就代表可以发布了吗？

不代表。还要复看实际声画、字幕可读性、素材来源和片尾，并核对个人信息及发布授权。规则检查、CI 和脱敏脚本各有范围，不证明版权已全部清理或声音已匿名化。问题反馈请使用[贡献指南](../CONTRIBUTING.md)，公开 Issue 不要放原始私人录音或密钥。
