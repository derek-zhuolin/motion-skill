# 能力矩阵

按工程边界列出12项能力，不把研究数量当自动生产能力。

| ID | 能力 | 适用范围 | 实际边界 |
|---|---|---|---|
| F01 | 真实媒体probe | 通用工具 | 时长、轨道、哈希、能量停顿候选；不是ASR |
| F02 | 原声1×时间轴 | 通用模板 | 长度/offset约束；不自动全轨变速 |
| F03 | 5类语义结构 | 通用模板 | collect / connect / compare / evidence / conclusion |
| F04 | 阅读预算 | 通用工具 | 汉字、英文词分开；从content_ready计时，参数可调 |
| F05 | 共享对象约束 | 工具＋reference | ID声明校验不证明像素连续；reference有贯穿对象 |
| F06 | 人工声画落点与机位 | 契约＋reference | 不自动识别语义重音、音乐节拍或生成任意机位 |
| F07 | 帧级底部字幕 | 模板＋reference | voice默认检查字幕存在；reference另附SRT，长句要复看 |
| F08 | 真人画中画 | 通用模板 | 只用输入视频；不生成人脸，未做人脸跟踪 |
| F09 | 实拍图片与视频混剪 | reference已实现 | 有来源、静音5.4秒B-roll；非自动素材匹配服务 |
| F10 | 可调整配色 | 模板＋reference＋研究主色 | 配置主色、底色与墨色；实拍和材质不一键全改 |
| F11 | 本地预览与研究库 | 通用模板 | 播放/暂停/seek；96项研究，19类；不主张96项发明 |
| F12 | 导出与工程验证 | 工具＋reference | H.264/AAC；类型/构建/帧/规则/脱敏检查，人类观感另验收 |

历史组合仍保留在源码和目录中，当前UI未开放，不宣称它们是可用生产模板。

本reference实际为7段镜头、25条字幕、1张照片和5.4秒实拍视频。完整原声48.064秒，1080p/30fps。

输入不仅限于录音：`script`模式支持按文稿与阅读时间编排无口播动效；`voice`模式使用真实音频时间轴。SFX与BGM可作为制作要求，但当前没有内置音效库或自动混音管线，不计入已实现的能力项。见[声音说明](AUDIO.md)。
