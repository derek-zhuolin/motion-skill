# ACE-Step：官方下载、首次等待与 Motion 配合使用

ACE-Step 是可选的外部本地音乐生成工具，不是 Motion Skill 自带模型。**只想试律动 Playground，不需要安装 ACE-Step**；示例随代码合成测试节拍。有现成且获授权的音乐，也可以直接进入配乐与画面的编排。

## 从哪里下载

- [ACE-Step 官方 GitHub](https://github.com/ace-step/ACE-Step-1.5)：获取项目与最新说明。
- [官方中文安装指南](https://github.com/ace-step/ACE-Step-1.5/blob/main/docs/zh/INSTALL.md) / [English installation guide](https://github.com/ace-step/ACE-Step-1.5/blob/main/docs/en/INSTALL.md)：按自己的系统和硬件选择安装方式。

**使用者从官方来源自行安装即可，不需要 Motion Skill 维护者重新上传程序或模型。** 本仓库提供工作流与入口，不镜像 ACE-Step 程序或模型权重；安装或更新 Motion Skill 不会安装它们。下载 GitHub 源码 ZIP 也不代表模型已下载、环境已装好。

1. 先检查已有 ACE-Step 安装、模型缓存及可用磁盘，能复用就不重复下载。
2. 按官方指南选择对应系统和硬件的路线，不把某台 Mac 的配置直接套给所有人。
3. 上游首次启动可能自动下载模型。启动前确认所选模型、空间和等待时间；模型从上游指定的 Hugging Face / ModelScope 等来源获取，不需要下载所有模型。
4. 下载慢时先看进度和日志；确有连接错误再按官方指南选择下载源，不反复重启或重复提交生成任务。
5. 安装并启动成功后，生成一条短样本，确认可播放并试听，再把音频文件交给 Motion 工程编排。这里只提供接入说明，不是内置的一键安装或自动配乐服务。

## 第一次使用先知道这几件事

- **下载比较大**：上游安装指南列出核心模型约 **10GB** 磁盘需求。实际组合可能是数 GB 到 10GB 以上，加上 Python 依赖、可选语言模型及缓存还需要更多空间。上游首次运行可能自动下载模型；请在执行前告知使用者并确认其选择。
- **首次不只是生成**：安装依赖、下载模型、首次加载、生成音乐，是不同的等待阶段。首次下载可能需要几十分钟或更久，取决于网络、镜像和所选模型；本项目没有测得一个可承诺的首次总耗时。
- **缓存可复用**：已经下载的模型通常不用每次重下。重复失败先查下载、内存、健康状态或任务状态，不要不断重启同一个生成请求。
- **本机实测只作参考**：一次 Apple Silicon / MPS、turbo、关闭语言模型的实验生成 29 秒、请求 116 BPM 的无歌词配乐，服务记录的生成时间为 **243.75 秒（约 4 分 4 秒）**。这不含下载/首次加载，也不是别的机器的性能保证；请求 BPM 不等于成品每个强拍都准确。

以上实测为 2026-10-28 的单次记录，不包含个人配音，也不公开本机日志与路径。硬件和模型选择不同，耗时及效果会变化。上游要求与下载说明见 [ACE-Step 官方安装指南](https://github.com/ace-step/ACE-Step-1.5/blob/main/docs/en/INSTALL.md)。

## 直接复制给 Agent

> 我想用本地 ACE-Step 配合 Motion Skill 做视频配乐。先检查电脑是否已经安装 ACE-Step、模型是否齐全，能复用就不要重装。没有安装时，请参考官方 GitHub https://github.com/ace-step/ACE-Step-1.5 和中文安装指南，根据我的系统、硬件和磁盘空间给出安装方式。下载前明确告诉我模型较大、首次可能等待很久，让我确认后再下载。装好后先生成一条 10 秒的 K-pop 风格纯音乐供我试听；确认后再按实际片长制作，按音乐节奏编排动效，点击、转场、落定的音效另行制作或选用有许可的音源。音乐、音效和配音分轨，人声要清楚，最终提供可播放的 Playground 和带声音的 MP4。

把「10 秒」「K-pop」替换为自己的试听时长和风格即可。ACE-Step 负责生成配乐；动作音效的选择、落点和混音仍需在视频工程里完成，不会因为装好模型就自动配齐。

## 推荐制作顺序

1. 确认片长、是否纯音乐、风格、已有音乐是否可用；新生成先只做一条短样本。
2. 试听音乐结构，记录可用段落和真实起音。能播放、BPM 字段正确，不代表风格满意。
3. 将重要语义落点与音乐起音结合，给读数/证据保留停顿；真实视频和原声保持原时间。
4. 音乐、人声、动作音效分轨制作，在点击/进入/落定处安排少量动作音效，并检查人声清晰度、峰值和尾部。
5. 原速看听；换音乐后时间锚点与旧审片报告失效，重新核对。先通过 Playground，再决定扩展或导出。

**生成配乐、设计动作音效、挑选节奏落点，是三件事。** 本次工作流支持把它们组合，但没有自动识别所有强拍、自动配好每个音效或保证 K-pop 风格的功能。音乐质量与律动仍由实际试听决定。示例测试音只验证播放器与时间同步，不能用来证明 ACE-Step 的音乐品质。

安装和调用请使用上游当前文档或已安装、明确授权的 ACE-Step Skill；本仓库不静默安装模型，不捆绑下载，不修改服务配置。
